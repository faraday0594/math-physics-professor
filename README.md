# 🎓 Profesor IA de Matemáticas y Física (MiniMax + SymPy + Matplotlib)

Plataforma interactiva de resolución matemática y física paso a paso con motor científico en Python (`SymPy`, `NumPy`, `SciPy`, `Matplotlib`) y modo **Aula Interactiva por Diapositivas**.

## Características
- **Resolución Paso a Paso con LaTeX y Gráficas**: Verifica simbólica y numéricamente cada problema.
- **Modo Aula Interactiva (Slides)**: Genera clases magistrales paso a paso con intuición geométrica, sumas de Riemann, antiderivadas y autoevaluación.
- **Motor Científico Local de Respaldo**: Funciona incluso sin saldo de API gracias al motor simbólico integrado con SymPy y Matplotlib.
